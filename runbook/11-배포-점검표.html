「회차 번호를 받아 적는다」가 무슨 뜻인가

469장 전부에 같은 번호표가 붙습니다. 그것이 회차 번호입니다.

  • 어디에 나오나 — 이 명령이 맨 처음과 맨 끝에 찍습니다.
  • 왜 적나 — 잘못됐을 때 그 번호 하나로 469장을 통째로 되돌립니다.
  • 안 적으면 — 화면 기록을 뒤져야 합니다. 터미널을 닫았으면 더 어렵습니다.
🔴 종이에 적으세요. 「복사해 두기」도 중간에 다른 걸 복사하면 날아갑니다.
🔴 --out 은 /app 밖이어야 합니다 — 안이면 스크립트가 거절합니다.
⑤ SQL 로 결과를 본다 
sudo docker exec -it dss-pg-app psql -U dss_app -d dss_as
select count(*) as 흔적,
       sum(jsonb_array_length(coalesce(metadata->'attachmentIds','[]'::jsonb))) as 첨부,
       sum(jsonb_array_length(coalesce(metadata->'usedPartIds','[]'::jsonb)))   as 사용부품
  from status_change_histories
 where metadata->>'source' = 'KYOSAN_REPORT'
   and metadata->>'importBatchId' = '<회차>';
🔴 흔적은 전용 표가 아니라 status_change_histories 에 있습니다. 전용 표를 찾으면 없습니다.
